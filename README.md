## 🚀 Featured Projects

### 1. [MalwareVision — Explainable AI-Powered Malware Analysis Platform](https://github.com/nagateja8185/MalwareVision)
- Hybrid malware detection pipeline fusing static PE header disassembly with dynamic runtime behavioral analysis.
- Powered by Python, Scikit-learn, and **SHAP (Explainable AI)** to output feature attribution charts explaining malicious scores to SOC analysts.
- Automated threat intelligence enrichment mapped against **MITRE ATT&CK** techniques.

### 2. [SafeTalk.ai — Behavioral Cyber Harassment Detection](https://github.com/nagateja8185/safetalk.ai)
- Contextual threat detection platform using fine-tuned **BERT, RoBERTa, and DeBERTa** transformer models.
- Identifies grooming, bullying, coercion, and sextortion across multi-turn conversational exchanges with temporal memory buffers.
- Multilingual NLP and SHAP-based feature importance for actionable parental and moderation intervention.

### 3. [SteganoSafe — Zero-Trust Secure File Sharing System](https://github.com/nagateja8185/stegano-safe)
- Confidential file transfer pipeline combining military-grade **AES-256-GCM** encryption with least-significant-bit (LSB) image steganography.
- Conceals encrypted payloads inside standard lossless PNG images without perceptual distortion.
- Role-Based Access Control (RBAC), salted key derivation, and tamper-proof SQLite security audit logging.

### 4. [PhishShield — AI-Powered Phishing Threat Detection](https://github.com/nagateja8185/PhishShield)
- Automated URL, email, and website phishing analyzer combining Random Forest and Logistic Regression ML classifiers.
- Multi-layered safety probes: WHOIS domain registration age, DNS resolution records, SSL/TLS certificate validity, and URL entropy.
- Computes an actionable 0–100 Trust Score designed for security operation center (SOC) triage.
